# Alpha 7 — Список возможностей

## Основной секвенсор
- Реальное время MIDI секвенсора
- Linear режим
- Loop режим
- Запись в реальном времени
- Запись по трекам
- Назначение MIDI каналов на трек
- 16 треков, 1024 событий на трек
- Буфер проекта 24 KB
- Стабильный транспорт (play / stop / pause)

## Запись и лупинг
- Count-in перед записью
- Метроном с акцентом
- Overdub в loop режиме
- Очистка трека (REC во время REC)
- Выравнивание записи по такту
- Workflow MIDI лупера в реальном времени

## MIDI функции
- Запись Note On / Note Off
- Sustain (CC64) запись и воспроизведение
- Глобальный transpose
- MIDI Clock (24 PPQN)
- MIDI Start / Stop / Continue
- MIDI DIN выход

## Управление
- Tap tempo (в режиме stop)
- Panic (FF + REW → All Notes Off)
- Живое наслаивание лупа
- Без квантизации (что сыграл — то и получил)

## Хранение
- Chained save система
- Секторное хранение
- Save / Load / Clean проекта
- Восстановление последнего проекта
- Безопасная работа с flash

## Web Tool
- Подключение через WebSerial
- Экспорт BIN / MIDI
- Импорт BIN / MIDI
- Поддержка MIDI Type 0 и 1
- Handshake загрузки (READY / DONE)
- Передача чанками
- Защита от переполнения

## Стабильность
- Overdub после loop работает стабильно
- Сортировка событий
- Нет зависаний на больших MIDI
- Проверки входных данных
- All Notes Off защита

## Ограничения (Alpha 7)
- Только 4/4
- Нет pitch bend
- Нет mod wheel
- Нет long track
- Нет event pool

##
- Исправлена нестабильность энкодера (пропуски, дрожание, двойные шаги)
- Реализован корректный detent-based decoding (0b11)
- Работа энкодера теперь стабильная и предсказуемая
