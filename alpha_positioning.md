# Alpha Sequencer — Positioning

## Market Landscape

### Elektron (Digitakt / Digitone)
Strengths:
- Deep sequencing features
- Parameter locks
- Powerful sound design

Limitations:
- Complex workflow
- Menu-heavy
- Step-sequencing focused

👉 Alpha difference:
- No step grid
- No menu diving
- Real-time performance first

---

### Squarp (Pyramid / Hapax)
Strengths:
- Advanced MIDI sequencing
- Huge feature set
- Flexible routing

Limitations:
- High complexity
- Requires setup and planning
- Not immediate

👉 Alpha difference:
- Minimal setup
- Immediate playability
- Focus on flow, not features

---

### Akai MPC
Strengths:
- Full production environment
- Sampling + sequencing
- DAW-in-a-box

Limitations:
- Screen-heavy
- DAW-like workflow
- Less tactile timing feel

👉 Alpha difference:
- No screen dependency
- No DAW paradigm
- Pure performance tool

---

## Alpha Position

Alpha sits in a new category:

> Performance-first MIDI sequencer

Not:
- a groovebox
- a DAW replacement
- a step sequencer

---

## Core Differentiators

- Real-time recording only
- Deterministic timing
- Minimal UI
- No visual editing
- Hardware-first thinking

---

## Strategic Insight

Others optimize for:
- features
- flexibility
- production

Alpha optimizes for:
- timing
- feel
- performance

---

## Summary

Elektron → creative programming  
Squarp → powerful control  
MPC → full production  

Alpha → **playing music in real time**
