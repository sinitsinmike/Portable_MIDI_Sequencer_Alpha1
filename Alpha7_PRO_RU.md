# Alpha 7 Release Notes (RU)

## Обзор
Alpha 7 — это первая стабильная версия секвенсора, ориентированная на надежность передачи данных, предсказуемость поведения и защиту от ошибок пользователя.

Основной фокус релиза:
- стабильность
- защита от переполнений
- базовая MIDI-совместимость (Type 0 / Type 1)
- поддержка sustain

---

## Основные изменения

### Буфер проекта
- Было: 16 KB
- Стало: 24 KB (24576 bytes)

➡️ Дало:
- больше событий
- меньше overflow
- стабильная работа с большими проектами

---

### Количество событий
- Было: ~500 событий на проект
- Стало: до 1024 событий на трек

⚠️ Ограничение:
- жесткий лимит 1024 / track (Alpha 7 safety)

---

### Новый механизм передачи (Upload)
- chunked HEX transfer
- задержки между пакетами
- ожидание READY / DONE
- таймауты

➡️ Убраны:
- зависания устройства
- разрывы передачи

---

### Защита от переполнения
Добавлено:
- проверка размера BIN перед отправкой
- проверка количества событий

Если превышено:
- загрузка отменяется
- пользователь получает лог

---

### MIDI Type 0 FIX
Ранее:
- устройство зависало

Теперь:
- корректный парсинг
- распределение по каналам
- защита от overflow

---

### Sustain (CC64)
Добавлено:
- запись
- воспроизведение
- импорт MIDI
- экспорт MIDI

---

### Transpose
Добавлен глобальный transpose:
- применяется на playback
- безопасный диапазон

---

### Общая стабильность
- устранены зависания
- улучшена обработка ошибок
- улучшены логи

---

## Breaking Changes

- Введен лимит 1024 событий на трек
- Большие MIDI файлы теперь не загружаются (раньше могли ломать устройство)
- Поведение Type 0 изменено (теперь безопасное)

---

## Ограничения Alpha 7

- Нет поддержки:
  - pitch bend
  - mod wheel
  - time signature (только 4/4)
- Фиксированный размер события (8 байт)
- Нет общего пула событий

---

## Roadmap → Alpha 8

### 1. Long Track Mode
- один трек = весь буфер
- для записи длинных соло

### 2. Event Pool
- общий пул событий
- динамическое распределение памяти

### 3. Оптимизация события
- уменьшение с 8 байт → 5–6 байт
- увеличение вместимости

### 4. Дополнительные MIDI CC
- mod wheel
- pitch bend
- расширенные контроллеры

---

## Итог

Alpha 7 — стабильная база:
- надежный upload
- защита от ошибок
- поддержка sustain
- увеличенный буфер

Это фундамент для Alpha 8.
